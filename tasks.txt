BIOS EFI DEBUG TOOLKIT

Open-source UEFI Shell toolkit for firmware developers to
inspect, diagnose, and collect system information.

PROJECT GOAL

Provide a lightweight, read-only EFI toolkit for common
BIOS/UEFI debugging tasks.
