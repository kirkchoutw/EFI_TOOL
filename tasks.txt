BIOS EFI DEBUG TOOLKIT

Open-source UEFI Shell toolkit for firmware developers to
inspect, diagnose, and collect system information.

PROJECT GOAL

Provide a lightweight EFI toolkit for common BIOS/UEFI
debugging tasks. Read-only by default; hardware writes
(PCI config / MMIO / I/O port / MSR) are opt-in:
io ... write asks [y/N] (or --force), the UI needs F2.
